# Public repository policy

This repository is the public front page for OmniCleaner.

## Published here

- Product overview and feature documentation.
- Safety and privacy documentation.
- Screenshots and approved marketing graphics.
- Patreon and Ko-fi support graphics.
- Issue templates for product feedback and documentation reports.
- Public licensing and security-policy information.

## Not published here

- Application source code.
- Tests, definitions, profiles, or internal scripts.
- Installers, uninstallers, executables, DLLs, or portable builds.
- Build output, symbol files, packages, archives, or update payloads.
- Code-signing certificates, secrets, tokens, keys, or internal infrastructure.
- Private development notes or unreleased implementation details.

The repository includes a defensive `.gitignore`, but publication is also reviewed with an explicit allowlist before each push.

## Contributions

Issues are welcome for reproducible bugs, feature proposals, documentation improvements, and accessibility feedback. Pull requests should be limited to public documentation and presentation assets. Application-code pull requests cannot be accepted here because the source is not hosted in this repository.
