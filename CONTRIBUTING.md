# Contributing

Thank you for helping improve OmniCleaner’s public documentation and product feedback.

## Welcome here

- Reproducible bug reports that include Windows architecture, OmniCleaner version, selected workspace, and expected versus observed behavior.
- Feature requests that explain the user problem, safety considerations, and expected value.
- Accessibility and usability feedback.
- Corrections to public documentation, screenshots, links, or marketing copy.

## Not accepted here

Application source-code contributions, compiled binaries, installers, rule packs, private builds, reverse-engineered code, and third-party proprietary assets are not accepted in this repository.

## Pull requests

Pull requests should contain only documentation or approved public presentation assets. Keep changes focused, explain the user-facing reason, and do not add executable or archived content.

## Security issues

Do not open a public issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md).
